## How to Add Images

1. Copy each fruit image to this folder
2. Rename them according to the table above
3. Recommended format: JPG or PNG
4. Recommended size: 300x300 pixels for optimal performance

## Alternative (Using Web URLs)

If you want to use web URLs instead, update the CATEGORIES array in `src/routes/index.tsx` to use image URLs from your CDN or hosting service.
